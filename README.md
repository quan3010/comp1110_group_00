## Description
This is an application to help users determine which moves to use when they are in a pokemon battle.

An example would be:
User input:
- Their pokemon: Squirtle
- Their opponent type: Fire

Expect output:
- You should use "Water Gun" and the damage is 80

User input:
- Their pokemon: Squirtle
- Their opponent type: Grass

Expect output:
- You should use "Tackle" and the damage is 70
